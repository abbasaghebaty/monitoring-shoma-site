# نقشه اولیه دامنه داده

> این سند صرفاً مدل مفهومی است. schema زنده D1 مرجع اجرایی است و نباید برای هماهنگی با مدل مفهومی یا کد قدیمی تغییر کند. برای ستون‌های تأییدشده و ناسازگاری queryها، [D1_COMPATIBILITY.md](D1_COMPATIBILITY.md) را ببین.

این سند مدل مفهومی است، نه schema قابل اجرا.

- Product: شناسه، نام، بارکد، دسته‌بندی، قیمت خرید/فروش، حداقل موجودی، وضعیت
- Sale: سربرگ فروش، مشتری، زمان، تخفیف، جمع کل، وضعیت
- SaleItem: محصول، تعداد، قیمت زمان فروش، بهای خرید snapshot
- Payment: روش، مبلغ، زمان، مرجع تراکنش
- Purchase و PurchaseItem: سند خرید و اقلام
- Customer و Supplier: اطلاعات پایه و مانده حساب
- StockMovement: ورود/خروج/اصلاح با سند مرجع
- Expense: دسته، مبلغ، تاریخ، توضیح
- AuditLog: عامل، عملیات، موجودیت، زمان و تغییرات

## تطبیق با دیتابیس موجود

نام جدول‌هایی که در کد ربات دیده می‌شوند، لزوماً وجود یا ساختار آن‌ها را در D1 زنده ثابت نمی‌کند. queryهای قدیمی باید با schema واقعی تطبیق داده شوند؛ دیتابیس برای سازگاری با آن queryها تغییر نمی‌کند. نام ستون‌ها، کلیدها، generated columns و triggerها فقط از snapshot واقعی D1 معتبرند. این سند هیچ جدولی ایجاد نمی‌کند و مجوز migration نیست.
