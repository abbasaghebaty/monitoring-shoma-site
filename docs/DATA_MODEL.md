# نقشه اولیه دامنه داده

این سند مدل مفهومی است، نه schema قابل اجرا.

- Product: شناسه، نام، بارکد، دسته‌بندی، قیمت خرید/فروش، حداقل موجودی، وضعیت
- Sale: سربرگ فروش، مشتری، زمان، تخفیف، جمع کل، وضعیت
- SaleItem: محصول، تعداد، قیمت زمان فروش، بهای خرید snapshot
- Payment: روش، مبلغ، زمان، مرجع تراکنش
- Purchase و PurchaseItem: سند خرید و اقلام
- Customer و Supplier: اطلاعات پایه و مانده حساب
- StockMovement: ورود/خروج/اصلاح با سند مرجع
- Expense: دسته، مبلغ، تاریخ، توضیح
- AuditLog: عامل، عملیات، موجودیت، زمان و تغییرات

## تطبیق با دیتابیس موجود

مخزن ربات از جداولی مانند products, purchases, purchase_items, sales, sale_items, payments, debts, customers و shortages استفاده می‌کند. نام ستون‌ها، کلیدها، triggerها و قواعد واقعی باید از migrationها و کد استخراج شوند؛ این سند هیچ جدولی ایجاد نمی‌کند.
