# نقشه راه اتصال فضای مدیریت انبار
اصل ثابت: هیچ صفحه یا قابلیت موجود حذف نمی‌شود؛ Schema فقط با Migration افزایشی و قابل بازبینی تغییر می‌کند. هیچ Migration روی Production بدون تأیید مستقل اجرا نمی‌شود.

## فاز اول
- [x] طراحی Migration افزایشی برای دسته‌بندی، برند، انبار، موقعیت و Audit
- [x] افزودن endpointهای احراز هویت‌شده و محدود به owner/manager
- [x] APIهای فهرست، ایجاد و ویرایش با کنترل هم‌زمانی
- [ ] اتصال رابط کاربری چهار صفحه و افزودن تست‌های کامل
