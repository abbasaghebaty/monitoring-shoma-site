# معماری کلان

## مرزبندی استقرار

- GitHub Pages: فقط فایل‌های استاتیک React/Vite
- Cloudflare Worker: API و منطق کسب‌وکار
- Cloudflare D1: دیتابیس موجود فروشگاه
- GitHub Actions: build و انتشار خودکار Pages

مرورگر هرگز مستقیماً به D1 وصل نمی‌شود. شناسه دیتابیس و secretها فقط در تنظیمات Worker باقی می‌مانند.

## اصول طراحی

1. ماژولار بودن دامنه‌ها: کالا، موجودی، فروش، خرید، مشتری، تأمین‌کننده، مالی، گزارش و تنظیمات.
2. ابتدا خواندن امن داده‌ها؛ سپس نوشتن تراکنش‌ها.
3. هر عملیات مالی باید قابل ردیابی و دارای سند مرجع باشد.
4. مبالغ در API عدد صحیح تومان باشند؛ تبدیل نمایشی فقط در UI انجام شود.
5. زمان ذخیره‌سازی و timezone گزارش‌ها صریح و یکسان باشد.
6. هیچ داده نمایشی نباید با داده واقعی اشتباه گرفته شود.
7. تغییر schema دیتابیس موجود فقط پس از بررسی کامل و برنامه مهاجرت جداگانه.
