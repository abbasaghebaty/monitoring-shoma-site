# Shoma API Worker

این پوشه اسکلت بک‌اند Cloudflare Workers است؛ هنوز به جداول زنده وصل نشده است.

## اتصال به D1 موجود

1. مقدار placeholder در `wrangler.toml` را با شناسه دیتابیس موجود `shop-manager` جایگزین کن.
2. binding باید دقیقاً `DB` باشد.
3. مقدار `ALLOWED_ORIGINS` را در تنظیمات Worker برابر origin واقعی GitHub Pages قرار بده.
4. قبل از هر query، schema و migrationهای مخزن ربات فروشگاه را بررسی کن.
5. هیچ migration این پروژه را روی دیتابیس زنده اجرا نکن؛ این پوشه عمداً migration ندارد.

## مسیرهای فعلی

- `GET /health`: سلامت Worker
- مسیرهای `/api/v1/*`: فعلاً پاسخ 501 می‌دهند تا زمانی که queryها با schema واقعی تطبیق داده شوند.

## امنیت

- هیچ secret در Git یا متغیرهای `VITE_*` قرار نده.
- CORS احراز هویت نیست؛ قبل از ارائه اطلاعات مشتری/فروش، احراز هویت و مجوز مدیر باید اضافه شود.
- عملیات نوشتن فروش باید با D1 batch/transaction و کنترل موجودی پیاده‌سازی شود.
